ICI Infection Meta‑analysis
"The impact of immune checkpoint inhibitor on infection in patients with solid malignancies: a systematic review and meta‑analysis of randomized controlled trials"
Files
- `metaanalysis.R` – Main R script for all analyses
## File Descriptions
| File | Description | Corresponding Analysis |
| :--- | :--- | :--- |
| `metaanalysis.R` | Main R script for all meta‑analyses | All figures and tables |
| `anygrade TEAE.csv` | Any-grade treatment-emergent adverse events | Figure 2a, 3a, 3c |
| `anygrade TRAE.csv` | Any-grade treatment-related adverse events | Figure 2b, 3b, 3d |
| `grade3 TEAE.csv` | Severe (Grade 3–5) TEAE infections | Figure S1a |
| `grade3 TRAE.csv` | Severe (Grade 3–5) TRAE infections | Figure S1b |
| `Fatal TEAE.csv` | Fatal (Grade 5) TEAE infections | Figure S2a |
| `Fatal TRAE.csv` | Fatal (Grade 5) TRAE infections | Figure S2b |
| `respiratory.csv` | Respiratory tract infections | Figure S8 |
| `genitourinary.csv` | Genitourinary tract infections | Figure S9 |
| `sepsis.csv` | Sepsis or septic shock | Figure S10 |
| `febrile neutropenia risk.csv` | FN risk subgroup (ICI mono vs chemo) | Figure S4 |
| `Perioperative period.csv` | Perioperative timing subgroup (TEAE) | Figure S6 |
How to run
1. Download all files to the same folder
2. Open `metaanalysis.R` in RStudio
3. Run the entire script
